# Installing Spectrum Search

Spectrum Search is free, and every way below runs the same search page.
Pick your device.

- [Web — nothing to install](#web--nothing-to-install)
- [Windows](#windows)
- [Mac](#mac)
- [Chromebook](#chromebook)
- [iPad and iPhone](#ipad-and-iphone)
- [Android](#android)

## Web — nothing to install

Open either address in any browser:

- https://caeled.github.io/mis-classmate-portal/SpectrumSearch.html
- http://caeled.geekgalaxy.com/web/steve/phoenix/SpectrumSearch.html

The first address (on GitHub) is the one that can also be installed as an
app on a Chromebook, an iPad, or an Android phone, because installing needs
the secure https address. The second address is the author's own server;
the page works the same there, it just cannot offer the install.

## Windows

1. Go to the release page:
   https://github.com/caeled/spectrum-search-app/releases/tag/v0.8.0
2. Download **Spectrum.Search_0.8.0_x64-setup.exe** and run it.
3. Windows may say "Windows protected your PC." The app is not signed with
   a paid certificate, so this warning is expected. Choose **More info**,
   then **Run anyway**.

There is also an .msi on the same page (Spectrum.Search_0.8.0_x64_en-US.msi).
It is the same app in the installer format IT departments usually deploy.
Pick one; you do not need both.

## Mac

1. Go to the release page:
   https://github.com/caeled/spectrum-search-app/releases/tag/v0.8.0
2. Download **Spectrum.Search_0.8.0_universal.dmg** (one file works on both
   Apple silicon and Intel Macs).
3. Open the .dmg and drag Spectrum Search into Applications.
4. The first time you open it, **right-click the app and choose Open, then
   Open again**. The build is unsigned, so macOS asks once. After that it
   launches normally.

## Chromebook

1. Open Chrome and go to:
   https://caeled.github.io/mis-classmate-portal/SpectrumSearch.html
2. If you do not see an install icon yet, reload the page once. The first
   visit sets the install up.
3. Click the **Install** icon at the right end of the address bar, or open
   the **⋮ menu** and choose **Install Spectrum Search**.
4. Spectrum Search now sits in your launcher like any other app and opens
   in its own window.

School Chromebooks: a school administrator can block installs. If yours is
blocked, use the web address above. The page works with no install at all.

## iPad and iPhone

Installing on Apple devices goes through Safari. (Chrome on an iPad cannot
offer installs; that is Apple's rule, not a fault in the page.)

1. Open this address in **Safari**:
   https://caeled.github.io/mis-classmate-portal/SpectrumSearch.html
2. Tap the **Share** button, then **Add to Home Screen**, then **Add**.
3. Spectrum Search gets its own icon on your home screen and opens
   full-screen, like an app.

## Android

1. Open this address in **Chrome**:
   https://caeled.github.io/mis-classmate-portal/SpectrumSearch.html
2. Open the **⋮ menu** and choose **Install app** (on some phones it says
   **Add to Home screen**).
3. Spectrum Search opens from your home screen or app drawer like a
   regular app.

## Which version is which

- The Windows and Mac apps carry Spectrum Search **v0.8**.
- The web page, and anything installed from it (Chromebook, iPad, Android),
  is **v0.8.1**: the same search, plus the install support. The web copy is
  always the newest.
- Each copy keeps its own settings on its own device. Spectrum Search
  learns only on your device; nothing about your searching is uploaded.
